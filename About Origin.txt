首先 Count Anywhere 是一个手动计数器，一个为了辅助手动细胞计数而诞生的计数器。
但其实一开始，我是准备写一个包装 Cellpose-SAM 的 Web API 的，
但是因为自身的强迫症，感觉在安全问题上找不准怎么设计与解决，就被搁置了。
后来我在直接推广 Cellpose 的时候意识到了，Cellpose-SAM 是比较吃算力的（虽然跑完一个测试图，拿 NVIDIA RTX A4000 和纯 CPU（Intel 的某代 i7，
前者只用了几秒，后者也不过几分钟），而且实际上也存在一些错误需要纠正，导致部分人仍然保守的选择使用手动计数。
但是这种手动计数没有圈画，完全靠瞪眼和感觉记忆，缺乏效率与可靠性（数着数着，一打岔还可能忘记数到哪了），
那么除了用纸笔圈画，我觉得还可以用一个针对计数操作进行优化的软件提高效率。
于是 Count Anywhere 就诞生了。

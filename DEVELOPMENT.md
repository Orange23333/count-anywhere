# Branches

After we released the first release, the development version will not be directly merged into the main branch.

# Project Information
## Version Code

- `release` like: `major`.`minor`.`build` or `major`.`minor`.`build`.`revision`
- `dev` like: `major`.`minor`.`build`a`revision`.dev`date`
  - `revision` 是用于确保版本号递增的。
